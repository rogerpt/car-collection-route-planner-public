# Car Collection Route Planner

A simple web app to add car registrations and UK postcodes, then calculate the most efficient collection route.

## Live Demo

Once GitHub Pages is enabled, the app will be available at:

**https://rogerpt.github.io/car-collection-route-planner-public/**

## How to use

1. Click **Load Sample Data** to load the example cars, or add your own.
2. Click **Calculate Most Efficient Route**.
3. View the optimised order on the map.

## Features

- Add / remove cars by registration + postcode
- Free UK postcode geocoding (postcodes.io)
- Nearest-neighbour route optimisation
- Interactive Leaflet map
- No login or API keys required
